# 문제 캡쳐 → 한글 삽입기

시험지를 캡쳐해 붙여넣으면 Gemini 가 글과 수식을 읽어, **실행 중인 한글(HWP) 커서 자리에**
원본과 같은 배치로 넣습니다. 수식은 그림이 아니라 **한글 수식 개체**로 들어가서 나중에 고칠 수 있습니다.

화면은 브라우저로 열리지만, 서버는 그 컴퓨터 안에서만 돕니다(`127.0.0.1`).
한글은 그 PC 에서만 조작할 수 있어서 — 인터넷에 올린 서버는 남의 PC 한글을 건드릴 수 없습니다 — 이렇게 만들었습니다.

## 쓰는 순서

1. `실행.bat` 더블클릭 (또는 `dist\문제캡쳐한글삽입기.exe`)
2. 처음 한 번만 — 설정에서 Gemini API 키 입력.
   키는 https://aistudio.google.com/apikey 에서 **무료**로 받습니다.
3. 한글에서 **문제를 담을 파일을 열고** 넣을 자리에 커서를 둡니다.
   앱은 새 한글을 띄우지 않고 **이미 켜져 있는 한글에 붙습니다.**
   화면 위 "넣을 한글 문서" 칸에서 대상 파일을 확인·선택하세요.
4. `Win + Shift + S` 로 문제를 캡쳐 → 앱 화면에서 `Ctrl+V`.
   **여러 문제를 한꺼번에** 넣어도 됩니다. 한 장씩 계속 붙여넣으면 아래에 쌓이고,
   기본 3개씩 **동시에** 인식합니다(설정에서 1~5로 조절).
5. 결과를 확인/수정한 뒤 **[모두 한글에 삽입]** (`Ctrl+Enter`) — 문제들이 차례로 들어갑니다.

설정에서 "인식 끝나면 바로 삽입"을 켜면 `Ctrl+V` 한 번으로 한글까지 들어갑니다.
인식이 영 이상하면 [이미지 그대로 삽입] 으로 캡쳐 그림을 넣을 수도 있습니다.
잘 안 될 때는 설정 → **[한글 연결 점검]**.

## 다른 노트북에 옮기기

`hwpmath-setup.zip` (약 34MB) 을 USB·클라우드·카톡 등으로 옮겨 풀면 됩니다.
**파이썬을 깔 필요 없습니다.** 그 컴퓨터에 한컴오피스 한글만 있으면 됩니다.
압축을 푼 폴더에서 exe 를 실행하고, 설정에서 API 키만 한 번 넣으면 끝입니다.
(설정은 exe 옆 `config.json` 에 저장되니, 키가 든 채로 남에게 주지 마세요.)

다시 만들려면:

```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed --name "문제캡쳐한글삽입기" --add-data "hwpmath/web;web" --hidden-import win32timezone run.py
```

## 인식 결과 마크업

인식 결과는 사람이 고칠 수 있는 형태로 나옵니다. 틀린 곳은 여기서 고친 뒤 삽입하세요.

```
3. 등비수열 $\{a_n\}$이

[[EQ]] a_3+a_5=60, \quad \frac{a_4}{a_2}+\frac{a_8}{a_6}=6

을 만족시킬 때, $a_1$의 값은? [3점]

[[CH]] ① $4$ | ② $\frac{9}{2}$ | ③ $5$ | ④ $\frac{11}{2}$ | ⑤ $6$
```

| 표시 | 뜻 | 한글에서 |
|---|---|---|
| `$...$` | 글 속에 섞인 수식 | 문장 안에 수식 개체 |
| `[[EQ]] ...` | 따로 떨어진 수식 줄 | 앞뒤 빈 줄 + 가운데 정렬 문단 |
| `[[CH]] a \| b \| c` | 객관식 보기 줄 | 한 문단에 탭 간격으로 나열 |
| 빈 줄 | 빈 줄 | 빈 문단 |

수식은 LaTeX 로 적습니다. `\frac{}{}`, `\sqrt{}`, `\sum`, `\int`, `\lim`, `\begin{cases}` 등을
한글 수식 스크립트(`{a} over {b}`, `sqrt {x}`, `sum from {} to {}` …)로 바꿔 줍니다.
[한글 수식 스크립트] 버튼으로 변환 결과를 볼 수 있습니다.

빈칸(네모 칸) 문제도 그대로 옮깁니다.

| 쓰는 법 | 한글에서 |
|---|---|
| `oxed{(가)}` | 네모 칸 안에 (가) |
| `oxed{\quad}` 또는 `\square` | 빈 네모 칸 |

예: `[[EQ]] b_{2n-1} = b_{2n} = oxed{(가)} \quad (n \geq 1)`

빈칸(네모 칸) 문제도 그대로 옮깁니다.

| 쓰는 법 | 한글에서 |
|---|---|
| `\boxed{(가)}` | 네모 칸 안에 (가) |
| `\boxed{\quad}` 또는 `\square` | 빈 네모 칸 |

예: `[[EQ]] b_{2n-1} = b_{2n} = \boxed{(가)} \quad (n \geq 1)`

> 한글 수식은 `_` 뒤를 공백 전까지 통째로 첨자로 먹습니다(`a_5=60` → 아래첨자가 `5=60`).
> 그래서 모든 첨자를 `a_{5}` 처럼 중괄호로 묶어 내보냅니다.
> 네모 칸은 한글 수식의 `box{...}` 명령으로 들어갑니다.
> 네모 칸은 한글 수식의 `box{...}` 명령으로 들어갑니다.

## 실행 방법

| 명령 | 하는 일 |
|---|---|
| `python run.py` | 브라우저로 열리는 앱 (기본) |
| `python run.py --port 9000` | 다른 포트로 |
| `python run.py --gui` | 예전 창(tkinter) 방식 |
| `python run.py --selftest` | 한글 삽입 점검, 결과를 `점검결과.txt` 로 |
| `python hwpmath/latex2hwp.py` | 수식 변환기만 시험 |

## 파일

| 파일 | 하는 일 |
|---|---|
| `run.py`, `실행.bat` | 실행 |
| `hwpmath/server.py` | 로컬 웹 서버 + API (한글 작업은 전담 스레드가 처리) |
| `hwpmath/web/index.html` | 브라우저 화면 |
| `hwpmath/ocr.py` | Gemini 로 이미지 → 마크업 |
| `hwpmath/markup.py` | 마크업 → 문단 블록 |
| `hwpmath/latex2hwp.py` | LaTeX → 한글 수식 스크립트 |
| `hwpmath/hwp_writer.py` | 한글 COM 조작 (문단 정렬·수식·탭 삽입) |
| `hwpmath/selftest.py` | 한글 연결/삽입 점검 (한 문제·여러 문제 모두) |
| `hwpmath/app.py` | 예전 tkinter 화면 (`--gui`) |

## 알아 둘 것

- Gemini 무료 등급은 분당·일일 요청 제한이 있고, 보낸 이미지가 구글의 모델 개선에 쓰일 수 있습니다.
- 인식은 완벽하지 않습니다. **삽입 전에 결과를 한 번 훑어보는 것**을 전제로 만들었습니다.
- 한글이 안 떠 있으면 새로 열라고 알려 줍니다(앱이 멋대로 새 한글을 띄우지 않습니다).
- 한글은 MS오피스와 달리 `GetActiveObject` 로 잡히지 않습니다. 실행 중인 개체 목록(ROT)에
  `!HwpObject.130.1` 로 등록되어 있어서, 그 목록을 뒤져 붙습니다 (`hwp_writer._running_hwp`).
- 넣기 직전마다 다시 붙으므로, 그 사이에 새로 연 문서에도 바로 들어갑니다.
- 앱을 끝낼 때는 화면 오른쪽 위 [종료] 를 누르세요(탭만 닫으면 서버가 계속 돕니다).
- 여러 문제를 한꺼번에 인식하면 무료 등급의 분당 요청 제한에 걸릴 수 있습니다.
  실패한 문제는 [모두 인식] 을 다시 누르면 실패한 것만 다시 시도합니다.
